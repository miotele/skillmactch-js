# skillmactch-js

o sistema adiciona um candidato com suas habilidades e experiencia e procura melhor vaga com as informaçoes inseridas 

Instale o node.js
Abra o Vscode 
File=>Open folder=>skillmactch-js
Abra o terminal ,digite:
node skillMatch.js execute

Calculo de porcentagem foi usado ,mesmmo se adicionar mais habilidades ainda sim seria possivel o calculo de compatibilidade

Foi recomendado as habilidades faltantes 

Class e this para montar a estrutura da vaga 
Herança para adicionar dentro da class
Promisse para simular um servidor 
Callback
Closure
Filter nas habilidades atendidas e Faltantes 
Map na criação dos resultados 
Find localização da vaga
Every validação da vaga 
Reduce melhor vaga

Apareceu em Promise
Cliente: computador ,navegador,aplicação>>faz requisição >>Servidor:processa dados ,banco de dados>>volta resposta para >>Cliente
